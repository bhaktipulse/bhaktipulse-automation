# BhaktiPulse Automation

Daily devotional YouTube Short automation.

## Workflow

Festival / Daily Topic
→ Content
→ AI Image
→ Visual Edit
→ Telugu Voice
→ MP4
→ Quality Validation
→ YouTube Schedule

## Publish Time

06:30 AM IST

## Rules

- Telugu + English YouTube title
- Maximum 60 characters
- Exact topic/deity visual
- Natural Telugu devotional voice
- 9:16 vertical MP4
- Quality validation before publishing
- No publishing if validation fails
